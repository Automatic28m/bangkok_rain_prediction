# ความเป็นมาของโครงงาน

## ปัญหา

ประเทศไทยเกิดน้ำท่วมแทบทุกปี เช่น มหาอุทกภัยปี 2554 (65 จังหวัด ความเสียหายราว 1.43 ล้านล้านบาท) น้ำท่วมภาคใต้ปี 2560 และเชียงรายปี 2567 ส่วนในเมืองยังเจอน้ำท่วมขังฉับพลันหลังฝนตกหนักแทบทุกฤดูฝน

แอปพยากรณ์อากาศทั่วไปตอบได้แค่ว่า *"ฝนจะตกไหม"* แต่ตอบไม่ได้ว่า *"ฝนมากพอจะท่วมไหม"* เพราะ:

1. **บอกแค่โอกาสฝน (%)** ไม่บอกว่าฝนจะตกมากแค่ไหน (มม.)
2. **ไม่มีระดับความเสี่ยง** ผู้ใช้ไม่รู้ว่าฝนกี่ มม. ถึงจะอันตราย
3. **ไม่รวมฝนสะสม** ทั้งที่น้ำท่วมเกิดจากฝนรวมทั้งวัน
4. **ไม่ใช้ข้อมูลและเกณฑ์ของกรมอุตุนิยมวิทยา (TMD)**

## วิธีแก้ของแอปนี้

- ดึงพยากรณ์ฝนรายชั่วโมง 24 ชั่วโมงจาก **TMD API** ครบ 77 จังหวัด
- รวมเป็น **ปริมาณฝน (มม.)** และ **โอกาสฝน (%)** แล้วสรุปเป็น 3 ระดับ:

| ระดับ | เงื่อนไข |
|-------|----------|
| 🔴 DANGER | ฝน ≥ 90 มม. หรือ (≥ 50 มม. และโอกาส ≥ 80%) |
| 🟡 WARNING | ฝน ≥ 35 มม. หรือ (≥ 20 มม. และโอกาส ≥ 70%) |
| 🟢 SAFE | นอกเหนือจากนั้น |

- บอก **เหตุผล** ทุกครั้ง และแสดงกราฟฝนรายชั่วโมงกับฝนสะสมเทียบเส้นเกณฑ์ในหน้าเว็บเดียว

ค่า 35 และ 90 มม. อ้างอิงเกณฑ์ "ฝนหนัก" และ "ฝนหนักมาก" ของ TMD ส่วนเงื่อนไขที่รวมโอกาสฝนเป็นเกณฑ์ที่ทีมกำหนดเพิ่ม

## ข้อจำกัด

ใช้เฉพาะพยากรณ์ฝน ยังไม่รวมระดับน้ำหรือการระบายน้ำ และไม่ใช่ประกาศเตือนภัยทางการ
