# การออกแบบ UI

หน้าเว็บเดียว ใช้ HTML, CSS และ JavaScript ล้วน (`src/main/resources/public/`) สไตล์เรียบ พื้นขาว ให้ข้อมูลเป็นพระเอก

## โครงหน้า

```
Know the rain. / Rest easy.               คำอธิบายสั้น (ชิดขวา)
[Live forecast] [Mock data]               ← แท็บเลือกแหล่งข้อมูล
[Where? | Forecast | Source | Check risk] ← แถบค้นหา
┌ สรุปผล ─┬ กราฟฝนรายชั่วโมง ─┬ แผนภาพเกณฑ์ ┐
│ ระดับ    ├ กราฟฝนสะสม ──────┤ + รายการกฎ   │
└─────────┴──────────────────┴─────────────┘
```

## แดชบอร์ด

| ส่วน | แสดงอะไร |
|------|----------|
| **สรุปผล** | ระดับความเสี่ยง, ฝนรวม (ตัวเลขใหญ่), มาตรวัดเทียบเกณฑ์, โอกาสฝน, ชั่วโมงที่ฝนหนักสุด, เหตุผล |
| **ฝนรายชั่วโมง** | กราฟแท่ง 24 ชั่วโมง มีปุ่ม Table สลับเป็นตาราง |
| **ฝนสะสม** | กราฟเส้นเทียบเส้น Warning 35 มม. และ Danger 90 มม. |
| **แผนภาพเกณฑ์** | โซน SAFE / WARNING / DANGER (ฝน × โอกาสฝน) และจุดของพยากรณ์นี้ |

## สีและตัวอักษร

- **สีพื้นฐาน:** พื้นขาว `#FEFEFE` ตัวอักษรดำ `#0B0E0C` และกรมท่า `#00286E` สำหรับปุ่มและแท็บ
- **สีสถานะ:** เขียว `#0ca30c`, เหลือง `#fab219`, แดง `#d03b3b` ใช้กับระดับความเสี่ยงเท่านั้น และมีไอคอนต่างรูปทรงกำกับเสมอ คนตาบอดสีจึงแยกได้
- **ฟอนต์:** Inter Display (พาดหัว) และ Inter (ข้อความ) โฮสต์เองในโฟลเดอร์ `fonts/`

## การทำงาน

- เปิดหน้าแล้วแสดงผลของ Bangkok ทันที
- ชี้เมาส์ที่กราฟเพื่อดูค่า
- ระหว่างโหลด แดชบอร์ดเดิมจางลงแทนการล้างหน้าจอ
- ข้อผิดพลาดแสดงเป็นแถบด้านบน
- ทั้งหน้าย่อขยายตามขนาดจอ บนมือถือเรียงเป็นแนวตั้ง
- มี animation ตอนเปิดหน้า และปิดให้อัตโนมัติถ้าผู้ใช้ตั้งค่าลดการเคลื่อนไหว
